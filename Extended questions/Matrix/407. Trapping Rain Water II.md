# 407. Trapping Rain Water II

## 解題程式碼

```javascript
var trapRainWater = function (heightMap) {
  const minQueue = new MinPriorityQueue((e) => e.height);
  let res = 0;

  for (let row of [0, heightMap.length - 1]) {
    // 把第一橫列和最後橫列的格子資訊加入 queue
    for (let i = 0; i < heightMap[0].length; i++) {
      minQueue.enqueue({ height: heightMap[row][i], x: row, y: i });
      heightMap[row][i] = -1; // 表示拜訪過
    }
  }

  for (let col of [0, heightMap[0].length - 1]) {
    // 把第一直欄和最後直欄的格子資訊加入 queue
    for (let i = 1; i < heightMap.length - 1; i++) {
      minQueue.enqueue({ height: heightMap[i][col], x: i, y: col });
      heightMap[i][col] = -1;
    }
  }

  while (minQueue.size()) {
    const { height, x, y } = minQueue.dequeue();

    for (const [newX, newY] of [
      [x, y - 1],
      [x, y + 1],
      [x - 1, y],
      [x + 1, y],
    ]) {
      if (newX < 0 || newX >= heightMap.length || newY < 0 || newY >= heightMap[0].length || heightMap[newX][newY] === -1) continue;

      res += Math.max(height - heightMap[newX][newY], 0);
      minQueue.enqueue({ height: Math.max(heightMap[newX][newY], height), x: newX, y: newY });
      heightMap[newX][newY] = -1;
    }
  }

  return res;
};
```

## 解題思路、演算法

思考的切入點可以從周圍一圈的格子思考，這些格子都不會積水，而且根據木桶原理，跟它們鄰近的水漥最高也就是周圍那圈的最矮格子高度，

因此首先可以用 Min Heap 儲存周圍一圈的格子高度，先取出最小高度的格子，

若取出的格子比某方向的格子大，就代表有機會往裡面灌水，灌水後要更新該格子的高度，代表已填充過，加回 heap，

接下來鄰近的水漥最高也就跟更新後的格子高度一樣，

，反之若取出的格子比某方向的格子小，加回 heap。

> 還有個思考點是一個格子最終的高，若可以灌水，最多就是從該格子到邊界這段路徑中的最小高度，因此可以聯想到最短路徑演算法 Dijkstra's Algorithm，這題算是一種變形

## 解法的時間、空間複雜度

時間複雜度: `O(m * n * log (m * n))`
空間複雜度: `O(m * n)`
