# 367. Valid Perfect Square

## 解題程式碼

```javascript
var isPerfectSquare = function (num) {
  let l = 0;
  let r = num;

  while (l <= r) {
    const mid = Math.floor((l + r) / 2);

    if (mid * mid === num) {
      return true;
    } else if (mid * mid > num) {
      r = mid - 1;
    } else {
      l = mid + 1;
    }
  }

  return false;
};
```
