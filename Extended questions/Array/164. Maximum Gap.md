# 164. Maximum Gap

## 解題程式碼

基數排序解：

```javascript
var maximumGap = function (nums) {
  if (nums.length < 2) return 0;

  let maxNum = Math.max(...nums);
  let exp = 1; // 指數

  while (Math.floor(maxNum / exp) > 0) {
    const buckets = new Array(10).fill().map(() => []);

    // 將數字分配到對應的桶
    for (let i = 0; i < nums.length; i++) {
      let digit = Math.floor(nums[i] / exp) % 10;
      buckets[digit].push(nums[i]);
    }

    // 收集桶中的數字，回寫到 nums
    let index = 0;
    for (let i = 0; i < 10; i++) {
      for (let j = 0; j < buckets[i].length; j++) {
        nums[index++] = buckets[i][j];
      }
    }

    exp *= 10;
  }

  // 計算最大相鄰差
  let maxGap = 0;
  for (let i = 0; i < nums.length - 1; i++) {
    maxGap = Math.max(maxGap, nums[i + 1] - nums[i]);
  }

  return maxGap;
};
```

桶子排序解：

```javascript
var maximumGap = function (nums) {
  const min = Math.min(...nums);
  const max = Math.max(...nums);
  if (max - min < 2) return max - min;

  const interval = Math.ceil((max - min) / (nums.length - 1)); // 表示答案至少是桶子的最大區間
  // nums = [3,6,9,1]，interval = Math.ceil((9 - 1) / (4 - 1)) = 3
  // 如果 m=1, M=9，那么 d=⌈8/3⌉=3，分成三个桶 1,2,3 ∣ 4,5,6 ∣ 7,8,9。
  const buckets = new Array(Math.floor((max - min) / interval) + 1).fill().map(() => [Infinity, -Infinity]);

  for (const num of nums) {
    const bucket = buckets[Math.floor((num - min) / interval)];
    bucket[0] = Math.min(bucket[0], num); // 維護桶内元素的最小值和最大值
    bucket[1] = Math.max(bucket[1], num);
  }

  let res = 0;
  let prevMax = Infinity;
  for (const [minVal, maxVal] of buckets) {
    if (minVal !== Infinity) {
      // 非空桶
      res = Math.max(res, minVal - prevMax);
      prevMax = maxVal;
    }
  }

  return res;
};
```

## 解題思路、演算法

拆分成多個桶子後，最大的間距一定不會出現在相同桶子內。

例如假設有一個空桶子 B，則最大間距可能出現在 A 最大到 C 最小相減後的數字。

怎麽保證至少有一個空桶子呢？

看靈神詳解 [详细解释 O(n) 分桶法（Python/Java/C++/C/Go/JS/Rust）](https://leetcode.cn/problems/maximum-gap/solutions/2772242/xiang-xi-jie-shi-on-fen-tong-fa-pythonja-mi5s/)

## 解法的時間、空間複雜度

時間複雜度: 基數排序 `O(n * k)`，n 為要排序的數字總數，k 為數字的位數。桶子排序 O(n)。
空間複雜度: O(n)
