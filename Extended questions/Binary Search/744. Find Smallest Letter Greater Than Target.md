# 744. Find Smallest Letter Greater Than Target

## 解題程式碼

第一次解：

```javascript
var nextGreatestLetter = function (letters, target) {
  let l = 0;
  let r = letters.length - 1;

  while (l <= r) {
    const mid = Math.floor((l + r) / 2);

    if (letters[mid] <= target) {
      if ((letters[mid] === target && letters[mid + 1] !== target && letters[mid + 1]) || (letters[mid] < target && letters[mid + 1] > target))
        return letters[mid + 1];
      l = mid + 1;
    } else {
      r = mid - 1;
    }
  }

  return letters[0];
};
```

更簡潔：

```javascript
var nextGreatestLetter = function (letters, target) {
  let l = 0;
  let r = letters.length - 1;

  while (l < r) {
    const mid = Math.floor((l + r) / 2);

    if (letters[mid] > target) {
      r = mid; // 大概知道為什麼不要 - 1 了，letters[mid] 本身有可能就是題目要的答案，所以不排除在外，而是選擇逐步逼近 l 指針
    } else {
      l = mid + 1;
    }
  }

  return letters[r] > target ? letters[r] : letters[0];
};
```

## 解題思路、演算法

兩種情況 `letters[mid] === target && letters[mid + 1] !== target` 或是 `letters[mid] < target && letters[mid + 1] > target` 就回傳找到的對應值。

記得使用 `letters[mid + 1]` 確保此值存在，不然 `mid === letters.length - 1 `時找不到值。

以下舉例：

```
letters = ['a', 'b', 'c', 'd', 'e'], target = 'd'
l = 0, r = 4, mid = 2
l 變成 3，mid = 3，符合第一種

letters = ['a', 'c', 'e', 'g', 'i'], target = 'f'
l = 0, r = 4, mid = 2，符合第二種
```

## 解法的時間、空間複雜度

時間複雜度: O(log n)
空間複雜度: O(1)
