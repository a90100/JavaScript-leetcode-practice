# 402. Remove K Digits

## 解題程式碼

```javascript
var removeKdigits = function (num, k) {
  const stack = [];
  for (let n of num) {
    while (k && stack.length && stack[stack.length - 1] > n) {
      k--;
      stack.pop();
    }
    // 若 n 為 0 且 stack 為空，不加入 stack，反之的條件則加入
    if (n !== '0' || stack.length !== 0) stack.push(n);
  }

  // 若是單調遞增情況，永遠不會進到 while 迴圈裡面
  // num = 123456，k = 3，k 不會用完，所以要擷取前面 num.length - k 個元素
  if (k > 0) stack.splice(-k);

  return stack.length === 0 ? '0' : stack.join('');
};
```

## 解題思路、演算法

關鍵想法：對於兩個數 123a456 和 123b456，如果 a > b， 那麽數字 123a456 大於 數字 123b456，否則數字 123a456 小於等於數字 123b456。也就說，兩個相同位數的數字大小關系取決於第一個不同的數的大小。

## 解法的時間、空間複雜度

時間複雜度: O(n)
空間複雜度: O(n)
