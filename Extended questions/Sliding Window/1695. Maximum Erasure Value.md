# 1695. Maximum Erasure Value

## 解題程式碼

```javascript
var maximumUniqueSubarray = function (nums) {
  const chars = new Set();
  let left = 0;
  let maxSum = 0;
  let curSum = 0;

  for (let i = 0; i < nums.length; i++) {
    while (chars.has(nums[i])) {
      chars.delete(nums[left]);
      curSum -= nums[left++];
    }

    chars.add(nums[i]);
    curSum += nums[i];
    maxSum = Math.max(maxSum, curSum);
  }

  return maxSum;
};
```

## 解題思路、演算法

維護一個 hashset 還有一個 sliding window，如果 hashset 有出現指定元素，就收縮 window。

## 解法的時間、空間複雜度

時間複雜度: O(n)
空間複雜度: O(n)
