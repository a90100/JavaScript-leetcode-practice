# 795. Number of Subarrays with Bounded Maximum

## 解題程式碼

```javascript
var numSubarrayBoundedMax = function (nums, left, right) {
  let l = -1;
  let r = -1;
  let res = 0;

  for (let i = 0; i < nums.length; i++) {
    if (nums[i] > right) r = i;
    if (nums[i] >= left) l = i;

    if (l > r) res += l - r;
  }

  return res;
};
```

## 解題思路、演算法

我們可以將 nums 內的元素分成三類來看：

1. 比 left 小
2. 在 [left, right] 之間
3. 比 right 大

維護兩個指針，指針 r 指向比 right 大的元素位置，指針 l 指向比 left 大或等於 left 的元素位置。

這些位置會隨著遍歷不斷更新。

則指針 l 和 r 之前的子陣列數目則為在題目要求下有效的子陣列數，可以加入結果。

在小於 left 時，指針 l 不用移動，例如範例 1. `[2]` 有效子陣列只有一組，遍歷到 index = 1 時，

`[2, 1]` 有效子陣列還是只有一組。

```
// 範例 2
// [2]
// [2]
// [5]
// [2, 5]
// [2, 5, 6]
// [5, 6]
// [6]

// 範例 3 nums = [2,9,5,6], left = 2, right = 8
// [2]
// [5]
// [5, 6]
// [6]
```

時間複雜度: O(n)
空間複雜度: O(1)
