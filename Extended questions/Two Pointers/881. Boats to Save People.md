# 881. Boats to Save People

## 解題程式碼

```javascript
var numRescueBoats = function (people, limit) {
  people.sort((a, b) => a - b);
  let res = 0;
  let l = 0;
  let r = people.length - 1;

  while (l <= r) {
    if (people[l] + people[r] <= limit) l++; // 判斷成立，代表小值和大值可以在同一艘船上並且不超過限重
    r--;
    res++;
  }

  return res;
};
```

## 解題思路、演算法

把 people 排序，讓一個重的人(大的值)配一個輕的人(小的值)，若總和小於等於 limit，就可以搭同一艘船，不然就只能讓重的人先搭船。

## 解法的時間、空間複雜度

時間複雜度: `O(n * log n)`
空間複雜度: O(1og n)，排序空間
