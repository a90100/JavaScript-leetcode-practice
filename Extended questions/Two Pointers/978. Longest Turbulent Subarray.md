# 978. Longest Turbulent Subarray

## 解題程式碼

第一次解題：使用 DP

```javascript
var maxTurbulenceSize = function (arr) {
  const evenLargeDP = new Array(arr.length).fill(1); // 大小大小大小...
  const oddLargeDP = new Array(arr.length).fill(1); // 小大小大小大...

  for (let i = 1; i < arr.length; i++) {
    if (i % 2 === 1) {
      if (arr[i] > arr[i - 1]) {
        // evenLargeDP 不符合規則，保持 1
        // oddLargeDP 符合規則(小大)，依照前一個數加 1
        oddLargeDP[i] = oddLargeDP[i - 1] + 1;
      } else if (arr[i] < arr[i - 1]) {
        // evenLargeDP 符合規則(大小)，依照前一個數加 1
        // oddLargeDP 不符合規則，保持 1
        evenLargeDP[i] = evenLargeDP[i - 1] + 1;
      }
    } else {
      if (arr[i] > arr[i - 1]) {
        // evenLargeDP 符合規則(大小)，依照前一個數加 1
        // oddLargeDP 不符合規則，保持 1
        evenLargeDP[i] = evenLargeDP[i - 1] + 1;
      } else if (arr[i] < arr[i - 1]) {
        // evenLargeDP 不符合規則，保持 1
        // oddLargeDP 符合規則(小大)，依照前一個數加 1
        oddLargeDP[i] = oddLargeDP[i - 1] + 1;
      }
    }
  }

  return Math.max(...evenLargeDP, ...oddLargeDP);
};
```

優化第一次解：

```javascript
var maxTurbulenceSize = function (arr) {
  const evenLargeDP = new Array(arr.length).fill(1); // 大小大小大小...
  const oddLargeDP = new Array(arr.length).fill(1); // 小大小大小大...
  let maxLen = 1;

  for (let i = 1; i < arr.length; i++) {
    if ((i % 2 === 1 && arr[i] > arr[i - 1]) || (i % 2 === 0 && arr[i] < arr[i - 1])) {
      oddLargeDP[i] = oddLargeDP[i - 1] + 1;
    }
    if ((i % 2 === 1 && arr[i] < arr[i - 1]) || (i % 2 === 0 && arr[i] > arr[i - 1])) {
      evenLargeDP[i] = evenLargeDP[i - 1] + 1;
    }
    maxLen = Math.max(maxLen, oddLargeDP[i], evenLargeDP[i]);
  }

  return maxLen;
};
```

DP 解還可以更簡化，參考 [一张动图详解动态规划，DP才是最容易理解的解法](https://leetcode.cn/problems/longest-turbulent-subarray/solutions/596686/yi-zhang-dong-tu-xiang-jie-dong-tai-gui-wrwvn/) 的解法。

Sliding Window: 自己想到的解

```javascript
var maxTurbulenceSize = function (arr) {
  let maxLen = 1;
  let l = 0;
  let r = 1;

  // 處理 edge case arr = [100,100,100]
  while (arr[l] === arr[r]) {
    l++;
    r++;
  }

  while (r < arr.length) {
    // r 指針可以繼續向右移的情況 arr[r - 1] < arr[r] && arr[r] > arr[r + 1] 或是 arr[r - 1] > arr[r] && arr[r] < arr[r + 1]
    // 不能往右移，就只能重頭開始累計 Turbulent Subarray
    if (!(arr[r - 1] < arr[r] && arr[r] > arr[r + 1]) && !(arr[r - 1] > arr[r] && arr[r] < arr[r + 1])) l = r;
    r++;

    maxLen = Math.max(maxLen, r - l + 1);
  }

  return maxLen;
};
```

## 解題思路、演算法

找符合特定規則的區間，可以想到 Sliding Window。

而一個 Turbulent Subarray 實際上可以由很多個子 Turbulent Subarray 組成，所以也可以想到動態規劃，記錄指定元素位置上的最長 Turbulent Subarray 長度。

## 解法的時間、空間複雜度

時間複雜度: O(n)
空間複雜度: O(1)
