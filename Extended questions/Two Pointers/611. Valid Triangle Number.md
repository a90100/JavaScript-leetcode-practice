# 611. Valid Triangle Number

## 解題程式碼

### 解法 1. 二分解法：

```javascript
var triangleNumber = function (nums) {
  nums.sort((a, b) => a - b);
  let validNum = 0;

  for (let i = 0; i < nums.length - 2; i++) {
    for (let j = i + 1; j < nums.length - 1; j++) {
      let left = j + 1;
      let right = nums.length - 1;
      let pos = j;

      while (left <= right) {
        const mid = Math.floor((left + right) / 2);

        if (nums[i] + nums[j] > nums[mid]) {
          // 代表還可以往右找更大，但可能 mid 就是最小的值
          pos = mid;
          left = mid + 1;
        } else {
          right = mid - 1;
        }
      }
      validNum += pos - j;
    }
  }

  return validNum;
};
```

### 解法 2. 固定最長邊：

```javascript
var triangleNumber = function (nums) {
  nums.sort((a, b) => a - b);
  let validNum = 0;

  for (let i = 2; i < nums.length; i++) {
    let l = 0;
    let r = i - 1;

    while (l < r) {
      if (nums[l] + nums[r] > nums[i]) {
        validNum += r - l;
        r--;
      } else {
        l++;
      }
    }
  }

  return validNum;
};
```

#### 優化可參考參考資料的靈神解，它提到的組合公式推導如下

#### 共 k +1 個數，要隨機取出 3 個，會出現幾種組合?

> 以下 ChatGPT 回答：

✅ 計算公式如下：

$$
\binom{k + 1}{3} = \frac{(k + 1)(k)(k - 1)}{6}
$$

✅ 解釋：

- $\binom{n}{r}$ 是「從 $n$ 個物品中選出 $r$ 個不重複且不考慮順序」的組合數。
- 這裡 $n = k + 1$，而我們要取出 $r = 3$ 個。

##### 為什麼分母是 6？

分母的 6 來自於「**組合公式**」的基本定義：

$$
\binom{n}{r} = \frac{n!}{r!(n - r)!}
$$

當我們從 $n = k + 1$ 個數中選出 $r = 3$ 個時：

$$
\binom{k+1}{3} = \frac{(k+1)!}{3!(k+1-3)!} = \frac{(k+1)!}{3!(k - 2)!}
$$

接著把分子與分母展開：

分子：

$$
(k+1)! = (k+1)(k)(k-1)(k-2)!
$$

分母：

$$
3!(k-2)! = 6(k-2)!
$$

所以：

$$
\frac{(k+1)(k)(k-1)(k-2)!}{6(k-2)!} = \frac{(k+1)(k)(k-1)}{6}
$$

這就解釋了為什麼分母是 6，而分子是 $(k+1)(k)(k-1)$。

### 解法 3. 固定最短邊：

```javascript
var triangleNumber = function (nums) {
  nums.sort((a, b) => a - b);
  let validNum = 0;

  for (let i = 0; i < nums.length - 2; i++) {
    if (nums[i] === 0) continue;
    let l = i + 1;
    for (let r = i + 2; r < nums.length; r++) {
      while (nums[r] - nums[l] >= nums[i]) {
        l++;
      }
      validNum += r - l;
    }
  }

  return validNum;
};
```

## 解題思路、演算法

構成三角形的條件是：任兩邊的長度之和必須大於第三邊的長度，任意兩邊長度之差的絕對值必須小於第三邊的長度。

## 解法的時間、空間複雜度

時間複雜度: 二分解法 `O(n^2 * log n)`，其他解 O(n^2)
空間複雜度: O(1og n)，排序所需空間
