# 1208. Get Equal Substrings Within Budget

## 解題程式碼

第一次解題：

```javascript
var equalSubstring = function (s, t, maxCost) {
  let max = 0;
  let l = 0;

  for (let i = 0; i < s.length; i++) {
    if (s[i] !== t[i]) {
      let newCost = Math.abs(s[i].charCodeAt(0) - t[i].charCodeAt(0));

      while (l <= i && newCost > maxCost) {
        if (s[l] !== t[l]) {
          maxCost += Math.abs(s[l].charCodeAt(0) - t[l].charCodeAt(0));
        }
        l++;
      }
      maxCost -= newCost;
    }

    max = Math.max(max, i - l + 1);
  }

  return max;
};
```

## 解題思路、演算法

用兩個指針維護子字串相同的範圍，

遍歷 s 字串，每個字元和 t 字串比對，若不同，消耗 cost，

若 maxCost 被消耗完，那移動左指針，用來回收之前消耗的 cost。

> 沒想到還可以用前綴和 + 二分，只是時間複雜度更高。

## 解法的時間、空間複雜度

時間複雜度: O(n)
空間複雜度: O(1)
