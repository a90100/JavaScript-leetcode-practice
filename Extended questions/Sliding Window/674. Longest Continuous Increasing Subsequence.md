# 674. Longest Continuous Increasing Subsequence

## 解題程式碼

```javascript
var findLengthOfLCIS = function (nums) {
  let l = 0;
  let max = 1;

  for (let i = 1; i < nums.length; i++) {
    if (nums[i] <= nums[i - 1]) {
      l = i;
    } else {
      max = Math.max(max, i - l + 1);
    }
  }

  return max;
};
```
