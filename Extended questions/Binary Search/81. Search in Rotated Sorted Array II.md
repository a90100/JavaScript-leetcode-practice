# 81. Search in Rotated Sorted Array II

## 解題程式碼

第一次解題：

```javascript
var search = function (nums, target) {
  let l = 0;
  let r = nums.length - 1;

  while (l <= r) {
    const mid = Math.floor((l + r) / 2);
    if (nums[mid] === target || nums[l] === target || nums[r] === target) return true;

    // 前面條件舉例，nums = [4,5,6,6,7,0,1,2,4,4]，target = 5，l = 0，r = 9，index = 4，nums[mid] = 7，前半部到中點為 4~7，必為排序陣列
    // 後面條件舉例，nums = [2,5,6,0,0,1,2]，target = 3，l = 0，r = 6，index = 3，nums[mid] = 0，前半部到中點為 2~0，非排序陣列
    // 前面條件舉例，nums = [4,5,6,6,7,0,1,2,4,4]，target = 2，l = 0，r = 9，index = 4，nums[mid] = 7，中點到後半部為 7~4，非排序陣列
    // 後面條件舉例，nums = [2,5,6,0,0,1,2]，target = 1，l = 0，r = 6，index = 3，nums[mid] = 0，中點到後半部為 0~2，必為排序陣列
    // 相等時怎麼處理? nums = [1,0,1,1,1] / [1,1,1,0,1]
    // 前半段有序 => nums[mid] === nums[l]，裡面值都要相同
    // 後半段有序 => nums[mid] === nums[r]，裡面值都要相同

    if (nums[mid] > nums[l] || (nums[mid] === nums[l] && new Set(nums.slice(l, mid + 1)).size === 1)) {
      // 前半段有序
      if (target > nums[l] && target < nums[mid]) {
        r = mid - 1;
      } else {
        l = mid + 1;
      }
    } else if (nums[mid] < nums[r] || (nums[mid] === nums[r] && new Set(nums.slice(mid, r + 1)).size === 1)) {
      // 後半段有序
      if (target > nums[mid] && target < nums[r]) {
        l = mid + 1;
      } else {
        r = mid - 1;
      }
    }
  }

  return false;
};
```

優化：相等的情況，實際上可以直接將左右指針往內移動一個位置，因為經過前面 `if (nums[mid] === target || nums[l] === target || nums[r] === target)` 的比較，`nums[l]` 和 `nums[r]` 絕對不是 target。

```javascript
var search = function (nums, target) {
  let l = 0;
  let r = nums.length - 1;

  while (l <= r) {
    const mid = Math.floor((l + r) / 2);
    if (nums[mid] === target || nums[l] === target || nums[r] === target) return true;

    if (nums[mid] === nums[l]) {
      l++;
    } else if (nums[mid] === nums[r]) {
      r--;
    } else if (nums[mid] > nums[l]) {
      if (target > nums[l] && target < nums[mid]) {
        r = mid - 1;
      } else {
        l = mid + 1;
      }
    } else if (nums[mid] < nums[r]) {
      if (target > nums[mid] && target < nums[r]) {
        l = mid + 1;
      } else {
        r = mid - 1;
      }
    }
  }

  return false;
};
```

這也是一個解：只需判斷三個大情況 `nums[mid] === nums[l]`、`nums[mid] > nums[l]` 和 `nums[mid] < nums[l]`。

```javascript
var search = function (nums, target) {
  let l = 0;
  let r = nums.length - 1;

  while (l <= r) {
    const mid = Math.floor((l + r) / 2);
    if (nums[mid] === target) return true;

    if (nums[mid] === nums[l]) {
      l++;
    } else if (nums[mid] > nums[l]) {
      if (target >= nums[l] && target < nums[mid]) {
        r = mid - 1;
      } else {
        l = mid + 1;
      }
    } else if (nums[mid] < nums[l]) {
      if (target > nums[mid] && target <= nums[r]) {
        l = mid + 1;
      } else {
        r = mid - 1;
      }
    }
  }

  return false;
};
```

## 解題思路、演算法

將此題的 nums 陣列先去重，用 33. Search in Rotated Sorted Array 用這題的解法就可以解開，

用其他解法的話，就是多了額外處理重複值的部分。

## 解法的時間、空間複雜度

時間複雜度: 最壞情況 O(n)，值都相同，平均 O(log n)
空間複雜度: O(1)
