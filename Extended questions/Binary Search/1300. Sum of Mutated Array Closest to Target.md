# 1300. Sum of Mutated Array Closest to Target

## 解題程式碼

第一次解題：

```javascript
var findBestValue = function (arr, target) {
  let min = 0;
  let max = Math.max(...arr);

  // 這段程式碼目標是找出大於等於 target 的可能最接近值
  // 為 變形模板: 查找第一個大於等於給定值的元素 的變化
  while (min < max) {
    // 和模板不同的是，不使用等於，跳出迴圈時 min === max
    let mid = Math.floor((min + max) / 2);
    let sum = arr.reduce((tol, cur) => tol + Math.min(cur, mid), 0);

    if (sum < target) {
      min = mid + 1; // mid 肯定不是要找的值，所以略過
    } else {
      max = mid; // sum >= target，mid 可能是要找的值，所以不略過
    }
  }

  let smallerTargetSum = arr.reduce((tol, cur) => tol + Math.min(cur, min - 1), 0);
  let largerTargetSum = arr.reduce((tol, cur) => tol + Math.min(cur, min), 0);

  if (Math.abs(smallerTargetSum - target) > Math.abs(largerTargetSum - target)) {
    return min;
  } else {
    return min - 1;
  }
};
```

時間複雜度: `O(n * log n)`
空間複雜度: O(1)
