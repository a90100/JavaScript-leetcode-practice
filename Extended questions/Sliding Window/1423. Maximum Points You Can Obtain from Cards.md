# 1423. Maximum Points You Can Obtain from Cards

## 解題程式碼

第一次解題：

```javascript
var maxScore = function (cardPoints, k) {
  let curSum = 0;
  let leftK = k - 1;

  for (let i = 0; i < k; i++) {
    curSum += cardPoints[i];
  }
  let res = curSum;

  for (let i = cardPoints.length - 1; i > cardPoints.length - k - 1; i--) {
    curSum += cardPoints[i] - cardPoints[leftK--];
    res = Math.max(res, curSum);
  }

  return res;
};
```

## 解題思路、演算法

因為是要從頭和尾去取得卡片，所以乍看起來好像不是求一段連續範圍的最大值，但如果把陣列看成一個環狀的話，就是求一段連續範圍的最大值。

所以可以用滑動窗口解，另個想法是因為從頭尾拿了 k 張卡，剩下的為 n - k 張卡，而且它們是連續的，所以求這個範圍中的最小值，然後題目要的結果就是陣列總和減去這個最小值。

## 解法的時間、空間複雜度

時間複雜度: O(n)
空間複雜度: O(1)
