# 852. Peak Index in a Mountain Array

## 解題程式碼

```javascript
var peakIndexInMountainArray = function (arr) {
  let l = 0;
  let r = arr.length - 1;

  while (l <= r) {
    let mid = Math.floor((l + r) / 2);
    if (arr[mid] > arr[mid - 1] && arr[mid] > arr[mid + 1]) {
      return mid;
    } else if (arr[mid] < arr[mid - 1]) {
      r = mid - 1;
    } else if (arr[mid] < arr[mid + 1]) {
      l = mid + 1;
    }
  }
};
```

## 解題思路、演算法

舉例 `arr = [0,1,2,4,5,10,5,2]`，

每次找到中點 ex `arr[3] = 4`，判斷左右邊的數，如果左右邊的數都比 4 小，那它就是峰值。

## 解法的時間、空間複雜度

時間複雜度: O(log n)
空間複雜度: O(1)
