# 467. Unique Substrings in Wraparound String

## 解題程式碼

```javascript
var findSubstringInWraproundString = function (s) {
  const lengthMap = new Map();
  let curLen = 0;

  for (let i = 0; i < s.length; i++) {
    if (i > 0 && (s[i].charCodeAt() + 26 - s[i - 1].charCodeAt()) % 26 === 1) {
      curLen++;
    } else {
      curLen = 1;
    }
    lengthMap.set(s[i], Math.max(curLen, lengthMap.get(s[i]) ?? 0));
  }

  let sum = 0;
  lengthMap.forEach((value) => {
    sum += value;
  });
  return sum;
};
```

## 解題思路、演算法

由題目範例可知，`s = "zab"` 的話，可以得到 z、za、zab、a、ab、b 共 6 個子字串，如果後面再加上一個字母 c，就再增加 4 種題目要求的子字串，增加幾種可以從前面遍歷過的連續字母數決定，zabc，四個連續字母，可得知 4 種。

特別情況，如果 `s = zabxyza`，遍歷到 b 時，總共有 6 種，z、za、zab、a、ab、b

但是碰到 x 就不連續，重新計算，但是遍歷到最後，這樣 za 的部分會重覆到，所以實際上我們可以用一個 hash map 記錄每個字母為結尾的子字串，有幾種，例如以 z 為結尾有 1 種，a 為 2、b 為 3、x 為 1、y 為 2，

z 的部分會重複計算，但是 xyz 比單純的 z 多了好幾種字串，那不如就把原本紀錄的種類數(1) 給覆蓋，也就是以 z 為結尾的子字串有 3 種，遍歷到 a，則有 4 種，

等於總共子字串種類有 3(b) + 1(x) + 2(y) + 3(z) + 4(a) = 13 種。

## 解法的時間、空間複雜度

時間複雜度: O(n)
空間複雜度: O(c)，c 為字母種類數
