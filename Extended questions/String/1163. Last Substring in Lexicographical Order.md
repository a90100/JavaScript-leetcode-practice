# 1163. Last Substring in Lexicographical Order

## 解題程式碼

```javascript
var lastSubstring = function (s) {
  let left = 0;
  let right = 1;
  let checkPos = 0;

  while (right + checkPos < s.length) {
    if (s[left + checkPos] === s[right + checkPos]) {
      checkPos++;
    } else if (s[left + checkPos] < s[right + checkPos]) {
      // ex: s = "ab"，那 left 會移動到 1
      left += checkPos + 1;
      if (left >= right) right = left + 1;
      checkPos = 0;
    } else {
      right += checkPos + 1;
      checkPos = 0;
    }
  }

  return s.slice(left);
};
```

## 解題思路、演算法

題目要的解，肯定是一個後綴子字串(也就是從字串中的某個位置 i 到字串最後一個字元的範圍)，因為前綴相同的子字串，長度越長的字典序會越靠後。

舉例，`s = "leetcotce"`，子字串 `tcotc` 會排在 `tcotce` 之前。

解題程式碼執行過程舉例：

```
ex: s = "zzzazzzzzz"
left = 0, right = 1, checkPos = 0
left = 0, right = 1, checkPos = 1
left = 0, right = 1, checkPos = 2，碰到 s[2] 為 z，s[3] 為 a，進到 s[left + checkPos] > s[right + checkPos] 判斷
left = 0, right = 4, checkPos = 0
left = 0, right = 4, checkPos = 1
left = 0, right = 4, checkPos = 2
left = 0, right = 4, checkPos = 3，碰到 s[3] 為 a，s[7] 為 z，進到 s[left + checkPos] < s[right + checkPos] 判斷
left = 4, right = 5, checkPos = 0
left = 4, right = 5, checkPos = 1
left = 4, right = 5, checkPos = 2
left = 4, right = 5, checkPos = 3
left = 4, right = 5, checkPos = 4
left = 4, right = 5, checkPos = 5，跳出迴圈
```

時間複雜度: O(n)
