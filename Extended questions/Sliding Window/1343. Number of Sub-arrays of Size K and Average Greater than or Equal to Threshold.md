# 1343. Number of Sub-arrays of Size K and Average Greater than or Equal to Threshold

## 解題程式碼

```javascript
var numOfSubarrays = function (arr, k, threshold) {
  let curSum = 0;
  let findArrNum = 0;

  for (let i = 0; i < arr.length; i++) {
    curSum += arr[i];
    if (i + 1 < k) continue;
    if (Math.floor(curSum / k) >= threshold) findArrNum++;
    curSum -= arr[i - k + 1];
  }

  return findArrNum;
};
```

## 解法的時間、空間複雜度

時間複雜度: O(n)
空間複雜度: O(1)
