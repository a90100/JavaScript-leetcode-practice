# 400. Nth Digit

## 解題程式碼

```javascript
var findNthDigit = function (n) {

  let intervalNums = 9;
  let intervalDigits = 1;
  while (n > intervalNums * intervalDigits) {
    n -= intervalNums * intervalDigits;
    intervalNums *= 10;
    intervalDigits++;
  }

  n--;
  let curNum = Math.pow(10, intervalDigits - 1) + Math.floor(n / intervalDigits); // 算出第 n 個 digit 會在哪個數字
  n = n % intervalDigits; // 該數字的索引

  return +('' + curNum)[n];
};
```

## 解題思路、演算法

先判斷 n 字元所在的數字，其位數，如果是只有 1 位數，此範圍中只有 9 個數字，如下以此類推：

```
1 ~ 9 9 個 digits
10 ~ 99 90 * 2 個 digits
100 ~ 999 900 * 3 個 digits
以此類推...
```

設 n = 200，200 − 9 − 180 = 11，while 迴圈出來為 1，

100 101 102 103，可以知道第 11 個數為 0，也是答案，

轉換成 index 因為是從 0 開始，所以 - 1，變成 `'100101102103'[10] = 0;`。

## 解法的時間、空間複雜度

時間複雜度: O(log n)
空間複雜度: O(1)
