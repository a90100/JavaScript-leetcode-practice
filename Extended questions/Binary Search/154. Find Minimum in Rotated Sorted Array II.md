# 154. Find Minimum in Rotated Sorted Array II

## 解題程式碼

```javascript
var findMin = function (nums) {
  let l = 0;
  let r = nums.length - 1;

  while (l < r) {
    const mid = Math.floor((l + r) / 2);

    if (nums[mid] > nums[r]) {
      l = mid + 1;
    } else if (nums[mid] < nums[r]) {
      r = mid; // mid 有可能是最小值，所以不能略過此索引位置
    } else {
      r--;
    }
  }

  return nums[r];
};
```

## 解題思路、演算法

```
ex: [4,5,6,7,0,1,1,1,2,2,3,4]，換個角度想，也就是找到右排序部分 [0,1,1,1,2,2,3,4] 的第一個元素

若 nums[mid] > nums[r]，ex: [4,4,5,6,7,0,1]，最小值會在右排序的部分，也就是 [0,1]，所以 l = mid + 1
若 nums[mid] < nums[r]，ex: [0,1,7,4,4,5,6]，最小值會在左排序的部分，也就是 [0,1]，所以 r = mid
若 nums[mid] == nums[r]，ex: [4,4,0,1,4,4,4,4,4] or [4,4,4,4,4,0,1,4,4]，最小值無法確定在哪個部分，所以 r--
```

## 解法的時間、空間複雜度

時間複雜度: 最壞情況 O(n)，值都相同，平均 O(log n)
空間複雜度: O(1)
