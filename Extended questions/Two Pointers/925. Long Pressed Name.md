# 925. Long Pressed Name

## 解題程式碼

```javascript
var isLongPressedName = function (name, typed) {
  let nameIndex = 0;
  let typedIndex = 0;

  while (typedIndex < typed.length) {
    if (name[nameIndex] === typed[typedIndex]) {
      nameIndex++;
      typedIndex++;
    } else {
      while (typed[typedIndex] === typed[typedIndex - 1]) typedIndex++; // 移動到沒有不小心重複打字的位置
      if (name[nameIndex] !== typed[typedIndex]) return false;
    }
  }

  return nameIndex === name.length;
};
```

## 解題思路、演算法

遍歷 typed 字串一次，並和當前 nameIndex 指向的 name 字串中的字元做比較，

如果和當前 typedIndex 指向的 typed 字串中的字元相同，兩個指針就可以往後比較，

如果是不同的字，可以先做 while 迴圈略過重複打的字，

但如果略過後兩個指針指向的字元還是不一樣，就無法組成 name，return false。

## 解法的時間、空間複雜度

時間複雜度: O(n)
空間複雜度: O(1)
