# 410. Split Array Largest Sum

## 解題程式碼

```javascript
var splitArray = function (nums, k) {
  let l = Math.max(...nums);
  let r = nums.reduce((tol, cur) => (tol += cur), 0);
  let res = r;

  const canSplit = (largest) => {
    // 貪心演算法，判斷是否能拆成 <= largest 個總和為一組，並且子陣列數目 <= k，如果可以，代表 largest 可能是題目要的其中一個解
    let subArrs = 1;
    let curSum = 0;

    for (let num of nums) {
      curSum += num;
      if (curSum > largest) {
        curSum = num;
        subArrs++;
      }
    }
    return subArrs <= k;
  };

  while (l <= r) {
    const mid = Math.floor((l + r) / 2);

    if (canSplit(mid)) {
      res = mid;
      r = mid - 1;
    } else {
      l = mid + 1;
    }
  }

  return res;
};
```

## 解題思路、演算法

從題目可以知道若分割成越多個子陣列，陣列各自總和的最大值，可能會越小，

若分割成越少個子陣列，陣列各自總和的最大值，可能會越大，因為會由更多個元素加總，

此為觀察到的單調性。

並且最大子陣列的和不會超過整個陣列的和，可做為二分的初始右邊界，

然後陣列中最大元素值一定會在某組子陣列，所以陣列中使用最大元素值做為二分的初始左邊界。

## 解法的時間、空間複雜度

時間複雜度: `O(n * log s)`，n 為陣列長，s 為陣列總和。
空間複雜度: O(1)
