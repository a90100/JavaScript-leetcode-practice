# 1122. Relative Sort Array

## 解題程式碼

第一次解題：

```javascript
var relativeSortArray = function (arr1, arr2) {
  const hashMap = new Map();
  const res = [];

  for (let i = 0; i < arr1.length; i++) {
    hashMap.set(arr1[i], (hashMap.get(arr1[i]) || 0) + 1);
  }

  for (let i = 0; i < arr2.length; i++) {
    const repeatEles = [];
    for (let j = 0; j < hashMap.get(arr2[i]); j++) {
      repeatEles.push(arr2[i]);
    }
    hashMap.delete(arr2[i]);
    res.push(...repeatEles);
  }

  const remainKeys = [];
  for (var [key, value] of hashMap.entries()) {
    for (let i = 0; i < value; i++) {
      remainKeys.push(key);
    }
  }

  return [...res, ...remainKeys.sort((a, b) => a - b)];
};
```

實際上有更快的解法，可以自定義排序函式，排序規則有：

1. 如果比較的兩個元素都在 hashMap 中，則按照 arr2 中的順序進行排序。
2. 如果只有一個元素在 hashMap 中，則該元素排在前面。
3. 如果兩個元素都不在 hashMap 中，則按照數字大小排序。

```javascript
var relativeSortArray = function (arr1, arr2) {
  const hashMap = new Map();

  for (let i = 0; i < arr2.length; i++) {
    hashMap.set(arr2[i], i);
  }

  return arr1.sort((a, b) => {
    if (!hashMap.has(a) && !hashMap.has(b)) {
      return a - b;
    } else if (!hashMap.has(a)) {
      return 1; // 正數代表 b 要在 a 前
    } else if (!hashMap.has(b)) {
      return -1; // 負數代表 a 要在 b 前
    } else {
      return hashMap.get(a) - hashMap.get(b);
    }
  });
};
```
