# 1482. Minimum Number of Days to Make m Bouquets

## 解題程式碼

```javascript
var minDays = function (bloomDay, m, k) {
  if (m > bloomDay.length / k) return -1;
  let l = Math.min(...bloomDay);
  let r = Math.max(...bloomDay);

  const checkBouquets = (days) => {
    let l = 0;
    let foundBouquetsNum = 0;

    for (let i = 0; i < bloomDay.length; i++) {
      if (bloomDay[i] > days) {
        l = i + 1;
      } else {
        if (i - l + 1 >= k) {
          // 可以形成一束花
          foundBouquetsNum++;
          l = i + 1;
        }
      }
    }

    return foundBouquetsNum;
  };

  while (l < r) {
    let mid = Math.floor((l + r) / 2);

    if (checkBouquets(mid) >= m) {
      r = mid;
    } else {
      l = mid + 1;
    }
  }

  return l;
};
```

## 解題思路、演算法

超過一定天數符合可以找到 m 個花束，小於一定天數又不符合，符合二分搜尋的二段性，接下來觀察邊界，

最少天為 bloomDay 中最小值，最多天為 bloomDay 中最大值，邊界也有了就可以做二分搜尋。

判斷當前天數可以找到幾束花，用 checkBouquets 函式作處理，

如果 `checkBouquets(mid) >= m`，代表比當前 mid 天數還大的話，可以找到比目標 m 還多的花束，所以可以縮小右邊界，但 mid 有可能是答案，所以不排除掉。

如果 `checkBouquets(mid) < m`，代表當前 mid 天數不夠找到比目標 m 還多的花束，必須增加天數，所以放大左邊界。

## 解法的時間、空間複雜度

時間複雜度: `O(n * log(max(bloomDay) - min(bloomDay)))`，其中 n 為 bloomDay 的長度。
空間複雜度: O(1)
