# 85. Maximal Rectangle

## 解題程式碼

解法 1. 搭配 84. Largest Rectangle in Histogram 題解

```javascript
var largestRectangleArea = function (heights) {
  let maxArea = 0;
  heights.push(-1);
  let stack = []; // [[index, height]]

  for (let i = 0; i < heights.length; i++) {
    let start = i;
    while (stack.length != 0 && stack[stack.length - 1][1] > heights[i]) {
      let [index, height] = stack.pop();
      maxArea = Math.max(maxArea, height * (i - index));
      start = index;
    }
    stack.push([start, heights[i]]);
  }

  return maxArea;
};

var maximalRectangle = function (matrix) {
  let heights = matrix[0].map(Number);
  let maxArea = largestRectangleArea(heights);

  for (let i = 1; i < matrix.length; i++) {
    heights = matrix[i].map((ele, index) => (ele === '0' ? 0 : 1 + heights[index]));
    maxArea = Math.max(maxArea, largestRectangleArea(heights));
  }

  return maxArea;
};
```

解法 2.

> 暴力解 `O(m^2 * n)` 也能過

```javascript
var maximalRectangle = function (matrix) {
  const rows = matrix.length;
  const cols = matrix[0].length;
  const left = new Array(rows).fill(0).map(() => new Array(cols).fill(0));
  let maxArea = 0;

  for (let i = 0; i < rows; i++) {
    for (let j = 0; j < cols; j++) {
      if (matrix[i][j] === '1') {
        left[i][j] = (j === 0 ? 0 : left[i][j - 1]) + 1;
      }
    }
  }

  for (let i = 0; i < rows; i++) {
    for (let j = 0; j < cols; j++) {
      if (matrix[i][j] === '0') continue;

      let width = left[i][j];
      let area = left[i][j]; // 儲存當前橫列的寬，面積 1 * width
      for (let k = i - 1; k >= 0; k--) {
        // 由下往上查找橫列的寬
        width = Math.min(width, left[k][j]);
        area = Math.max(area, (i - k + 1) * width);
      }
      maxArea = Math.max(maxArea, area);
    }
  }
  return maxArea;
};
```

## 解法的時間、空間複雜度

時間複雜度: `O(m * n)`，m 為矩陣的橫列數，n 為矩陣的直欄數。
空間複雜度: O(n)，儲存一橫列的數字
