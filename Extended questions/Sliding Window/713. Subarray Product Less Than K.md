# 713. Subarray Product Less Than K

## 解題程式碼

```javascript
var numSubarrayProductLessThanK = function (nums, k) {
  let l = 0;
  let res = 0;
  let product = 1;

  for (let i = 0; i < nums.length; i++) {
    product *= nums[i];

    while (product >= k && l <= i) product /= nums[l++];
    res += i - l + 1;
  }

  return res;
};
```
