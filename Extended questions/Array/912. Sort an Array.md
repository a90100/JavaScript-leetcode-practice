# 912. Sort an Array

## 解題程式碼

```javascript
var sortArray = function (nums) {
  const minQueue = new MinPriorityQueue();

  for (let num of nums) {
    minQueue.enqueue(num);
  }

  let i = 0;
  while (minQueue.size()) nums[i++] = minQueue.dequeue();

  return nums;
};
```

## 解題思路、演算法

這題有很多的作法，排序演算法都可以用。

## 解法的時間、空間複雜度

時間複雜度: `O(n * log n)`
空間複雜度: O(n)
