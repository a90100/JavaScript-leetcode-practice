# 506. Relative Ranks

## 解題程式碼

```javascript
var findRelativeRanks = function (score) {
  const indexs = score
    .map((s, i) => ({ val: s, index: i }))
    .sort((a, b) => b.val - a.val)
    .map((o) => o.index);

  score[indexs[0]] = 'Gold Medal';
  score[indexs[1]] = 'Silver Medal';
  score[indexs[2]] = 'Bronze Medal';
  for (let i = 3; i < indexs.length; i++) {
    score[indexs[i]] = '' + (i + 1);
  }

  return score;
};
```

## 解題思路、演算法

## 解法的時間、空間複雜度

時間複雜度: `O(n * log n)`
空間複雜度: O(n)
