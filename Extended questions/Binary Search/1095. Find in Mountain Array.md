# 1095. Find in Mountain Array

## 解題程式碼

第一次解題：

```javascript
var findInMountainArray = function (target, mountainArr) {
  let l = 0;
  let r = mountainArr.length() - 1;
  let peakIndex = -1;

  // 先找到 mountainArr 的峰值位置
  // 然後先找峰值左邊的子陣列，看有沒有 target
  // 沒找到，找右邊的子陣列，看有沒有 target
  // 都沒找到，回傳 -1
  while (l <= r) {
    const mid = Math.floor((l + r) / 2);
    const curVal = mountainArr.get(mid);
    const prevVal = mountainArr.get(mid - 1);
    const nextVal = mountainArr.get(mid + 1);

    if (curVal > prevVal && curVal > nextVal) {
      peakIndex = mid;
      break;
    } else if (prevVal > curVal) {
      r = mid - 1;
    } else if (nextVal > curVal) {
      l = mid + 1;
    }
  }

  l = 0;
  r = peakIndex;
  // ex: [1,2,3,4,5]
  while (l <= r) {
    const mid = Math.floor((l + r) / 2);
    const curVal = mountainArr.get(mid);
    const prevVal = mountainArr.get(mid - 1);

    if (curVal === target && prevVal !== target) {
      return mid;
    } else if (curVal >= target) {
      r = mid - 1;
    } else {
      l = mid + 1;
    }
  }

  l = peakIndex;
  r = mountainArr.length() - 1;
  // ex: [5,4,3,2,1]
  while (l <= r) {
    const mid = Math.floor((l + r) / 2);
    const curVal = mountainArr.get(mid);
    const prevVal = mountainArr.get(mid - 1);

    if (curVal === target && prevVal !== target) {
      return mid;
    } else if (curVal >= target) {
      l = mid + 1;
    } else {
      r = mid - 1;
    }
  }

  return -1;
};
```

## 解題思路、演算法

分三段檢查，如註解所說，第一個 while 迴圈找峰值，可參考 852. Peak Index in a Mountain Array 的解，

後兩段可參考 Binary Search 筆記，變形模板：查找第一個值等於給定值的元素。

## 解法的時間、空間複雜度

時間複雜度: O(log n)
空間複雜度: O(1)
