# 1011. Capacity To Ship Packages Within D Days

## 解題程式碼

```javascript
var shipWithinDays = function (weights, days) {
  let l = Math.max(...weights);
  let r = weights.reduce((tol, cur) => (tol += cur), 0);

  const countDays = (limitWeight) => {
    let days = 1;
    let curWeight = 0;

    for (let weight of weights) {
      if (curWeight + weight > limitWeight) {
        days++;
        curWeight = 0;
      }
      curWeight += weight;
    }

    return days;
  };

  while (l < r) {
    const mid = Math.floor((l + r) / 2);

    const costDays = countDays(mid);

    if (costDays > days) {
      l = mid + 1;
    } else {
      r = mid;
    }
  }

  return l;
};
```

## 解題思路、演算法

題目提到在 days 天內要把所有 packages 搬完，求最小的每日運送重量，看到求最小值，有機會用二分解。

花費最多天：每天輸送的重量為 weights 中最大值，不可能會有比最大值小的情況，那樣的話該最大 package 無法搬上船，

花費最少天(1 天)：每天輸送的重量為 weights 總和，

所以我們可以定義**左邊界為 weights 中最大值，右邊界為 weights 總和**，

**大於一定每日運送重量就可以在 days 天內搬完，但小於一定的每日運送重量又沒辦法，符合二分搜尋的二段性**，左右邊界也有，確定可以用二分。

每次找到一個中間點 mid，用該中間點評估該重量需要幾天，

若找到的天數 > days，代表可能重量可以更重，`l = mid + 1`，

若找到的天數 <= days，代表可能重量可以更輕，但該找到天數也可能是答案，所以 `r = mid`。

## 解法的時間、空間複雜度

時間複雜度: `O(n * log (r - l))`，n 為 weights 的長度，r - l 為初始右邊界值減左邊界值。
空間複雜度: O(1)
