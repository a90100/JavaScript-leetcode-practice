# 1658. Minimum Operations to Reduce X to Zero

## 解題程式碼

第一次解題：

```javascript
var minOperations = function (nums, x) {
  const total = nums.reduce((tol, cur) => (tol += cur), 0);
  if (total === x) return nums.length;
  let maxRange = 0;
  let left = 0;
  let curSum = 0;

  for (let i = 0; i < nums.length; i++) {
    curSum += nums[i];
    while (curSum > total - x) curSum -= nums[left++];

    if (curSum === total - x) maxRange = Math.max(maxRange, i - left + 1);
  }

  return maxRange === 0 ? -1 : nums.length - maxRange;
};
```

官方：

```javascript
var minOperations = function (nums, x) {
  const sum = nums.reduce((tol, cur) => (tol += cur), 0);
  let right = 0;
  let lsum = 0,
    rsum = sum;
  let res = nums.length + 1;

  // 舉例 nums = [1,1,4,2,3], x = 5，一開始 rsum 為 11
  // 所以 while 迴圈會執行，直到 right 為 3 停止
  for (let left = -1; left < nums.length; left++) {
    if (left != -1) {
      lsum += nums[left];
    }
    while (right < nums.length && lsum + rsum > x) {
      rsum -= nums[right++];
    }
    if (lsum + rsum === x) {
      res = Math.min(res, left + 1 + (nums.length - right));
    }
  }

  return res > nums.length ? -1 : res;
};
```

## 解題思路、演算法

這題可以反向思考，題目轉換成**找出 total - x 的最大範圍(maxRange)**，所以可以先把所有 nums 值加總 total，

如果此時 total 等於 x，代表 nums 的長度就是答案。

如果不是，則使用滑動窗口找出 maxRange，最後用 nums.length - maxRange 即是題目所求。

## 解法的時間、空間複雜度

時間複雜度: O(n)
空間複雜度: O(1)
