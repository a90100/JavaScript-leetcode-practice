# 719. Find K-th Smallest Pair Distance

## 解題程式碼

```javascript
var smallestDistancePair = function (nums, k) {
  let l = 0;
  let r = Math.max(...nums);
  nums.sort((a, b) => a - b);

  // sliding window 找出小於等於 diff 的組合數目，nums 已經排序
  const findPairsLessOrEqualDiff = (diff) => {
    let l = 0;
    let res = 0;

    for (let r = 0; r < nums.length; r++) {
      while (nums[r] - nums[l] > diff) l++;

      res += r - l;
    }
    return res;
  };

  while (l < r) {
    const mid = Math.floor((l + r) / 2); // mid 為可能的 distance

    if (findPairsLessOrEqualDiff(mid) >= k) {
      // 比 k 多組，往右收斂
      r = mid; // 為什麼不是 r = mid - 1，舉範例 1 為例，若 k = 2，mid = 2 時，若將 r 變成 1 會不符合題目要求

      // 為什麼是 >= k，為什麼有等於
      // 舉例 nums = [1,3,1,3]、k = 2，第一輪 l = 0, r = 3, mid = 1，findPairsLessOrEqualDiff(1) = 2，剛好等於 k
      // 但很顯然 nums 有兩組相減後為 0，所以 mid = 1 不是最小的 distance，r 需要繼續往左收斂
    } else {
      l = mid + 1;
    }
  }

  return r;
};
```

## 解題思路、演算法

### 如何想到用二分?

觀察 nums 的最大最小可能值為 `0 <= nums[i] <= 10^6`，題目定義距離為兩個數相減的距離取絕對值，因此距離也必定在這個範圍內，

設將各對數字的距離畫成一個數線(或數軸)，設某距離為 d，距離小於 d 的對數為 count，

* count < k，則 d 太小了，應該猜更大的數
* count = k，則 d 可能是答案，剛好第 k 對就是 d，但也有可能例如 d - 1、d -2 也符合 count = k，所以要繼續猜測更小的數做嘗試
* count > k，則 d 太大了，應該猜更小的數

一邊符合某性質(count >= k 繼續往更小的猜)，一邊不符合，符合兩段性的特質，因此可以想到用二分。

### 知道要用二分了，如何想到上下邊界?

依照前面所述，二分的上下界就是距離的可能範圍，最小值為 `0`，最大值為 nums 陣列中的最大值。

### 如何快速計算小於等於當前的 mid (distance) 的 pair 有幾種組合?

暴力解是用雙層迴圈找出所有組合，但實際上可以用 sliding window 來解，不需要真的找出所有組合，

可以看參考資料 NeetCode 的影片，實際上問題就轉換為：

給你一個排序過的陣列，還有一個值 k，要你找出兩個數相減後的值要小於等於 k，這樣的兩個數有幾對?

舉例`[1,2,2,4,5,6,7]，k = 3`，有 14 對，

`[1,2]`，1 和 2 相減後的距離為 1，1 對，

`[1,2,2]`，2 對，`[1,2,2,4]`，3 對，再來 5 - 1 > 3，所以要移動左指針到 index = 1，

`[2,2,4,5]`，3 對，再來 6 - 2 > 3，所以要移動左指針到 index = 2，再到 3，

`[4,5,6]`，2 對，`[4,5,6,7]`，3 對。

## 解法的時間、空間複雜度

時間複雜度: `O(n * log n + n * log max)`，其中 `n` 是 `nums` 的長度，`max` 是 `nums` 中的最大值和最小值的差值。
空間複雜度: O(log n)，排序所需空間

不會過的作法：把所有距離組合都找出來：

```javascript
var smallestDistancePair = function (nums, k) {
  const pairs = new Map();

  for (let i = 0; i < nums.length; i++) {
    for (let j = i + 1; j < nums.length; j++) {
      const dis = Math.abs(nums[i] - nums[j]);
      pairs.set(dis, (pairs.get(dis) || 0) + 1);
    }
  }

  const sortKeys = [...pairs.keys()].sort((a, b) => a - b);
  for (let i = 0; i < sortKeys.length; i++) {
    const counts = pairs.get(sortKeys[i]);
    if (k > counts) {
      k -= counts;
    } else {
      return sortKeys[i];
    }
  }
};
```
